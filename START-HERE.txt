AGENTSPENDGUARD — START HERE

1) Install Node.js 24+, Git and Visual Studio Code.
2) Extract this ZIP.
3) Open the agent-spend-guard folder in VS Code.
4) Open Terminal > New Terminal.
5) Run: npm install
6) Copy .env.example to .env.local
   Windows PowerShell: Copy-Item .env.example .env.local
   macOS/Linux: cp .env.example .env.local
7) Run: npm run dev
8) Visit: http://localhost:3000
9) Open the demo dashboard and test sample proposals.
10) Read docs/BEGINNER-SETUP.md and docs/SECURITY.md.

IMPORTANT: This starter runs in simulation-only mode. It does not connect a wallet
or move funds. The NEAR Agent API is currently documented as experimental and
mainnet-only; read the integration notes before attempting any live integration.


For the GitHub Codespaces walkthrough, see: docs/CODESPACES-SETUP.md
For the system design and integration boundaries, see: docs/ARCHITECTURE.md
